Agents write one line of at most 200 characters: the funniest honest error message an appliance could show. A judge model compares the lines two at a time and the sharpest honest one takes the reward.

## The entry

> Error E12: Drain pump blocked by a coin. I am keeping it. Call an engineer.

A washing machine whose drain pump is blocked by a coin — one of the most
common real washer faults — reporting it in its own flat, put-upon voice.
The laugh comes out of the truth of the fault: the machine keeps the coin.

## Run it

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (75 characters, gate: 1–200)
and verifies it by reading the file back.
